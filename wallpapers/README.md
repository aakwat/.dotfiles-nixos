# Wallpapers

Drop `.png`, `.jpg`, `.jpeg`, or `.webp` files into this directory.

Step 3 of the root README copies everything in here to
`~/Pictures/Wallpapers/`. The `wallpaper` script picks one at random:

```bash
wallpaper                       # random
wallpaper ~/Pictures/foo.png    # specific
```

Hyprland autostarts `wallpaper` at login (see `.config/hypr/conf.d/autostart.conf`).

### Where to grab Catppuccin Mocha wallpapers

- <https://github.com/Gingeh/wallpapers> — official Catppuccin wallpapers
- <https://github.com/zhichaoh/catppuccin-wallpapers>
- <https://wallhaven.cc/search?q=catppuccin>
